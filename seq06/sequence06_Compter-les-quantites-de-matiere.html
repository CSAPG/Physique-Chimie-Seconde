2. Nombre d'entités N

Formule
N = méchantillon / mentité
N : nombre d'entités (sans unité) méchantillon : masse de l'échantillon en kg mentité : masse d'une entité en kg

Exercice Nombre de molécules de NH₃

La quantité de matière n

Manipuler des nombres comme 10²⁶ est peu pratique. Les chimistes regroupent les entités par « lots » de NA = 6,02×10²³ entités, appelés moles.
Formule fondamentale
n = N / NA
n : quantité de matière en mol N : nombre d'entités (sans unité) NA = 6,02×10²³ mol⁻¹ (constante d'Avogadro)

Exemple appliqué — CO₂ (10 kg)

Donnée : m(CO₂) = 7,35×10⁻²⁶ kg — échantillon m = 10 kg
Étape 1 — calculer N :
N = méchantillon / mentité = 10 / (7,35×10⁻²⁶)
↓
N = 1,4×10²⁶ molécules
Étape 2 — calculer n :
n = N / NA = (1,4×10²⁶) / (6,02×10²³)
↓
n = 2,3×10² mol

Masse d'une entité
Somme des masses de tous les atomes qui la composent ; si un atome apparaît plusieurs fois, on multiplie sa masse par ce nombre.
Nombre d'entités N
N = m(échantillon) / m(entité) : nombre d'entités (sans unité) dans un échantillon, à partir de sa masse et de la masse d'une entité.
Quantité de matière n
n = N / N_A : regroupe les entités par « lots » de N_A entités (moles), plus pratique que de manipuler des nombres comme 10²⁶.
Constante d'Avogadro N_A
N_A = 6,02×10²³ mol⁻¹ : nombre d'entités contenues dans une mole.
Mole
Unité de quantité de matière correspondant à un lot de N_A = 6,02×10²³ entités identiques.
