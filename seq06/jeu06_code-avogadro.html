Sortie débloquée

🔓 Évasion réussie !

Tu sors du laboratoire avec restantes sur l'horloge, après avoir mené l'échantillon de craie jusqu'au bout de la chaîne de calcul :

m(entité) = Σ m(atomes)
N = méchantillon / m(entité)
n = N / NA
As-tu remarqué que le chrono démarrait à 06 min 02 s ? Un clin d'œil à la constante d'Avogadro, NA = 6,02×1023 mol-1 — celle-là même que tu viens d'utiliser pour sortir.
Fermeture totale

01
La masse d'une entité
À résoudre

Le scanner moléculaire affiche la formule brute de l'échantillon : CaCO₃ (carbonate de calcium). Calcule la masse d'une entité à partir des masses atomiques ci-dessous.

AtomeMasse (kg)Nombre dans CaCO₃
Ca6,66×10-261
C2,00×10-261
O2,67×10-263
m(CaCO₃) = m(Ca) + m(C) + 3 × m(O)
kg
Additionne les trois contributions : 6,66×10-26 + 2,00×10-26 + 3 × 2,67×10-26.
02
Le nombre d'entités N
En attente

Le détecteur a pesé l'échantillon de craie : m = 5,0 g. Convertis cette masse en kg, puis calcule le nombre d'entités N qu'elle contient.

N = méchantillon / m(CaCO₃)
1 g = 10-3 kg, donc 5,0 g = 5,0×10-3 kg. Puis N = (5,0×10-3) / m(CaCO₃), avec la valeur trouvée à la serrure précédente.
03
La quantité de matière n — code de sortie
En attente

Dernière étape : convertis N en quantité de matière grâce à la constante d'Avogadro NA = 6,02×1023 mol-1. Le résultat est le code qui ouvre la sortie.

n = N / NA
mol
n = N / N_A, avec la valeur de N trouvée à la serrure précédente et N_A = 6,02×1023 mol-1.
