Énergie de vaporisation — Calcul critique
Le générateur de vapeur doit vaporiser 2 kg d'eau pour refroidir le cœur du réacteur. Calculez l'énergie nécessaire en kJ, puis convertissez en MJ pour trouver le code.

Données : Lv(eau) = 2 260 kJ/kg · m = 2 kg
Code = valeur en MJ (arrondi à l'entier)

Simulateur — explorez les valeurs :

4 kg

8000 kJ = 8 MJ

Avec m = 2 kg et Lv = 2 260 kJ/kg : Q = ? kJ = ? MJ. Le code = la valeur entière en MJ.

Q = 2 × 2260 = 4520 kJ. Conversion : 4520 kJ ÷ 1000 = 4,52 MJ ≈ 5 MJ (arrondi). Le code est 5.

Énigme 6 / 6 · ~10 min — Circuit F · CODE FINAL
Dissolution ionique & énergie associée
La salle de chimie contient du chlorure de sodium (NaCl). Pour refroidir le circuit en urgence, vous devez comprendre sa dissolution. Complétez l'équation, identifiez le type de transfert et calculez ΔH pour obtenir le code final.
dissolutionionsΔHendothermique
Partie A — Équation de dissolution

Cliquez sur un ion dans la palette, puis cliquez sur le blanc correspondant dans l'équation pour le placer.

NaCl(s) → (aq) + (aq)
Na⁺ Cl⁻ Na²⁺ OH⁻ H⁺ Cl₂
Partie B — Type de transfert thermique
Lorsqu'on dissout du NaCl dans l'eau, la température de la solution diminue légèrement par rapport à la température initiale.

La dissolution du NaCl est-elle endothermique ou exothermique ?

Partie C — Calcul de ΔH
ΔH = n × ΔH°diss

Données : ΔH°diss(NaCl) = +3,9 kJ/mol · n = 2 mol de NaCl dissous

2 mol
3.9 kJ/mol
+7.8 kJ

Avec n = 2 mol et ΔH°diss = +3,9 kJ/mol : ΔH = ? kJ. Le code final = cette valeur sans décimale (arrondi à 0.1 → entrez 7.8 → code = 8 arrondi à l'entier).

ΔH = 2 × 3,9 = 7,8 kJ. Le signe positif confirme que la dissolution est endothermique. Code = 8 (arrondi à l'entier).
